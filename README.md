# kenpadV1
kenpadV1 is a macropad with 6 keys and 1 rotary encoder(used for volume up/down and mute). It uses a custom PCB, 3D printed case, and QMK firmware.


## Features

- 6 key + rotary encoder layout
- [3D printed case](/Production)
- [Custom PCB](/PCB)
- [QMK firmware (keys and rotary encode)](/Firmware)


## Schematic

- Switches arranged in a matrix and with 1N4148 diodes.

## Case

- 4 through holes to secure the case and pcb.
